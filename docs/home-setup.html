Build your own home setup

Everything you need for a local AI workspace at home. Each category starts with the free option, then the paid upgrades.

Why build your own setup

You can run everything in this guide on the computer you already have. A dedicated home setup is worth it if you use AI every day: a machine with enough memory for bigger models, a second screen so the chat sits next to your work, and a comfortable keyboard and mouse for long sessions. Start with what you own, and upgrade one piece at a time when something slows you down.

You do not need to buy anything to follow this guide. Each category below starts with the free option, then lists paid upgrades for people who want a dedicated setup. Paid items are labeled as paid.

Computer to run your models

Free

The computer you own

Any Mac with Apple Silicon or a PC with 16 GB of memory runs a useful model. Start here, and buy only if Step 9 shows you need more.

Paid

Mac with lots of memory

On Apple Silicon, memory is shared with the graphics, so memory is the spec to pay for. Aim for 32 GB or more for bigger models.
