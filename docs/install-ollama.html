Install Ollama and a model

3Install Ollama

Ollama is the free program that manages and runs open-source models on your computer. Workspace apps connect to Ollama in the background to send and receive text. Download it from the official site at ollama.com/download.

Mac

  1. Download Ollama-darwin.zip from the download page.
  2. Double-click the zip file to unpack it, then drag the Ollama app into your Applications folder.
  3. Open Ollama from Applications. A welcome window will ask permission to install its command-line tool. Click Install and enter your Mac password when prompted.
  4. An Ollama llama icon appears in the top menu bar near the clock. Ollama is now running.

Windows

  1. Download OllamaSetup.exe and run the installer.
  2. Click Install. Once finished, Ollama starts quietly in the background.
  3. An Ollama icon appears in the Windows system tray (bottom-right near your clock).
  4. If you have an NVIDIA graphics card, ensure your NVIDIA driver is current via the GeForce Experience app or NVIDIA's site so Ollama can use CUDA acceleration automatically.

Linux

Open your terminal and run the official install script:

curl -fsSL https://ollama.com/install.sh | sh

The script installs the Ollama binary and sets up a systemd service that starts on boot.

Now verify that the command-line tool works. Open your terminal (Terminal on Mac, PowerShell or Command Prompt on Windows) and run:

ollama --version

What normal looks like: the terminal immediately prints something like ollama version is 0.5.x (or newer).

If this goes wrong

  • "Command not found" or "not recognized": completely close your terminal window and open a fresh one so your system reloads its path.
  • Mac security warning ("Cannot open because developer cannot be verified"): right-click the Ollama app in Applications, select Open, and click Open in the confirmation box.
  • Linux permission issues: ensure your user has permissions or run sudo systemctl status ollama to see if the service is active.
  • http://localhost:11434 says the site can't be reached: Ollama is installed but not running. Open the Ollama app once from Applications (Mac) or the Start menu (Windows), then reload the page.

Check: running ollama --version prints a version number without any error message.

4Download a model sized to your memory

Pick a model whose file size fits comfortably within your memory. As a rule of thumb, the model download should be no more than half your total RAM (or half your GPU VRAM on Windows/Linux). If a model is too large, your computer will swap memory to your hard drive, causing answers to crawl out one word every few seconds.

Now download and run your model. Type the run command for your memory tier into your terminal. For example, if you have 16 GB of RAM:

ollama run qwen3:8b

What normal looks like: you see a progress bar counting up to 100% as Ollama pulls each file layer. This takes between 2 and 10 minutes depending on your internet connection. Once finished, you see:

success
>>> Send a message (/? for help)

Type a simple test message, like What are three tips for clear writing? and press Enter. The model will stream its answer into your terminal. To exit back to your regular terminal prompt, type /bye and press Enter.

You can check which models are stored on your disk and what is currently loaded into memory with these two commands:

ollama list
ollama ps

If this goes wrong

  • Download freezes or fails: if your connection drops, press Ctrl + C and run the exact same ollama run command again. Ollama resumes from where it paused.
  • "Error: out of disk space": you don't have enough drive storage to extract the model weights. Free up space and try again.
  • Generation is painfully slow (less than 2 words per second): the model is too big for your machine and has spilled into disk swap. Type /bye, run ollama rm <model-name>, and try a smaller model like qwen3:4b.

Check: the model replied to your prompt in the terminal, and typing /bye returned you to your regular command line.

Frequently asked questions

How much disk space do AI models take up?

Downloads range from 2.5 GB for small 4-billion parameter models up to 20 GB or more for 30-billion parameter models. When stored on disk, they take up exactly what was downloaded.

Can I install and test multiple models?

Yes. You can download as many models as your disk space allows. Ollama switches between them on demand, keeping only the active model in system RAM.

What does the number in model names like 8b or 14b mean?

The number stands for billions of parameters (weights). More parameters generally mean deeper reasoning, better writing, and fewer mistakes, but require more memory and run slower.

How do I remove a model if I run out of disk space?

Run ollama list in your terminal to see all installed models, then run ollama rm followed by the model name (e.g. ollama rm qwen3:8b) to instantly reclaim space.
