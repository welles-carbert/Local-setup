Install Ollama and a model

Ollama is the free program that runs AI models on your computer. Install it, then download a model sized to your memory.

3Install Ollama

Ollama is the free program that downloads AI models and runs them on your computer. Every workspace app in this guide talks to your model through Ollama, so it goes in first. Get it from ollama.com/download.

Mac

  1. Download the Mac version, open the file, and drag Ollama into Applications.
  2. Open Ollama from Applications. If it asks to add its command to your system, allow it.
  3. On Apple Silicon it uses the graphics automatically. There are no drivers to install.

Windows

  1. Download the Windows installer and run it.
  2. Ollama starts in the background and shows an icon near the clock.
  3. If you have an NVIDIA card, keep its driver up to date so Ollama can use it.

Linux

Run the official install script:

curl -fsSL https://ollama.com/install.sh | sh

Then open a terminal (Terminal on Mac, PowerShell on Windows) and check it:

ollama --version

Check: the terminal prints a version number. If it says the command is not found, close the terminal, open it again and retry.

4Download a model sized to your memory

Pick a model whose download is no bigger than about half your memory. A model that is too big either will not load or answers painfully slowly. On a PC with a graphics card, size it to the card's memory for full speed. Bigger versions of the same model are smarter but slower, so start in your row and move up or down after you try it.

Your memoryAim for a download ofModels to start with
8 GBup to about 4 GBqwen3:4b (2.5 GB)
16 GBup to about 8 GBqwen3:8b (5.2 GB) or gemma4:12b (about 8 GB)
32 GBup to about 16 GBqwen3:14b (9.3 GB) or gemma4:26b (16 to 19 GB, a tight fit)
48 GB or more20 GB and upgemma4:31b (about 20 GB) or qwen3:30b (19 GB)

Sizes are from the Ollama library pages, checked November 6, 2026. They are starting suggestions, not benchmarks. Models change often, so check ollama.com/library for what is current.

Download and try the model in your terminal. Replace the name with the one from your row:

ollama run qwen3:8b

The first run downloads the model, which can take several minutes. Then a chat opens in the terminal. Ask it something, and type /bye to leave. These two commands show what you have downloaded and what is loaded right now:

ollama list
ollama ps

Check: the model answers a question at a speed you can live with. If replies crawl, pick a smaller model.
