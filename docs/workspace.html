Set up your workspace app

5Choose your workspace app

The workspace app provides the chat interface in your browser, replacing the web interfaces of Claude or ChatGPT. All three options below are free and connect directly to Ollama. If you are unsure, choose Open WebUI.

Recommended

Open WebUI

The closest direct replacement for a Claude project. Runs in your browser with custom model presets, system prompts, chat tagging, and document knowledge bases.

Requires: Docker. Best for: general desktop productivity and project workflows.

Free

LibreChat

A multi-model chat interface designed to look like ChatGPT. Can switch between your local Ollama models and external APIs (OpenAI, Anthropic, Mistral) in one place.

Requires: Docker and Git. Best for: power users who want local models alongside pay-as-you-go cloud keys.

Free

Hermes Agent

An autonomous agent from Nous Research designed for running multi-step tasks, shell commands, and terminal scripting.

Requires: a larger model (31b+) and command line comfort. Best for: replacing terminal coding agents.

Prefer a standard desktop app without Docker? Download LM Studio or AnythingLLM. Both install like ordinary apps. This guide focuses on Open WebUI because its knowledge base system mirrors Claude projects most closely.

Check: you have decided which app to install. (Most readers choose Open WebUI).

6Install Docker (for Open WebUI or LibreChat)

Docker runs your workspace app in an isolated software container. It ensures Open WebUI sets up cleanly on any operating system without complex manual package installations. Docker Desktop is free for personal, educational, and small business use.

Mac

  1. Download Docker Desktop for Mac. Select Apple Silicon (M1-M4) or Intel to match your Mac chip.
  2. Open the .dmg file and drag the Docker icon into your Applications folder.
  3. Open Docker from Applications. Accept the service agreement. Wait until the whale icon in your top menu bar shows a green dot indicating "Docker Desktop is running."

Windows

  1. Download Docker Desktop for Windows.
  2. Run the installer. Ensure the checkbox for Use WSL 2 instead of Hyper-V is checked.
  3. Restart your PC when prompted by the installer.
  4. Launch Docker Desktop from the Start menu. Wait until the bottom-left status indicator turns green with "Engine running."

Linux

Install the standard Docker Engine and Compose plugin for your distribution from docs.docker.com/engine/install, then start the service:

sudo systemctl enable --now docker

Test that Docker is ready by opening your terminal and running:

docker --version

What normal looks like: the command prints Docker version 27.x.x (or newer) and exits cleanly.

If this goes wrong:

  • Windows WSL 2 error ("WSL 2 installation is incomplete"): open PowerShell as Administrator and run wsl --update, then restart your computer.
  • "Cannot connect to the Docker daemon": Docker Desktop is not fully booted. Open the Docker Desktop application and wait 30 seconds for the engine to initialize.

Check: running docker --version returns a version number, and Docker Desktop shows the engine is running.

7Install the workspace and connect it to your model

Follow the instructions for your selected app. All apps talk to Ollama over local port 11434.

Option A: Open WebUI (Recommended)

Open your terminal and run the official start command:

Mac / Windows

docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main

Linux

On Linux, Docker runs directly on the host network so it can communicate with Ollama listening on 127.0.0.1:

docker run -d --network=host -v open-webui:/app/backend/data -e OLLAMA_BASE_URL=http://127.0.0.1:11434 --name open-webui --restart always ghcr.io/open-webui/open-webui:main

On Linux with host network, Open WebUI will be reached at http://localhost:8080 instead of 3000.

What normal looks like: Docker downloads the Open WebUI container image and prints a long string of letters and numbers (the container ID). Wait about 60 seconds for the internal server to start.

  1. Open your web browser and go to http://localhost:3000 (or http://localhost:8080 on Linux).
  2. Click Sign up. Enter any name, email, and password. This account is entirely local to your computer and never leaves your machine. The first account created becomes the Admin.
  3. Once logged in, look at the top model selection dropdown. Click it; your downloaded model (e.g. qwen3:8b) should appear automatically.
  4. Type a message into the chat bar and hit send.

If this goes wrong:

  • The browser says "Unable to connect" or "Site can't be reached": Open Docker Desktop, click Containers, and check if open-webui is green. If it is yellow or stopped, wait a minute or click the Play icon.
  • Model menu is empty: Ollama is either closed or unreachable. Make sure the Ollama menu icon is visible. In Open WebUI, go to User Profile (bottom left) → Admin Panel → Settings → Connections. Verify the Ollama URL is set to http://host.docker.internal:11434 (or http://localhost:11434 on Linux) and click the refresh icon.
  • Port 3000 is already in use: change -p 3000:8080 in the run command to -p 3005:8080, then open http://localhost:3005.

Check: you can open Open WebUI in your browser and receive a generated response from your model.

Option B: LibreChat

If you prefer LibreChat, clone its repository and configure its connection to Ollama:

git clone https://github.com/LibreChat-AI/LibreChat.git
cd LibreChat
cp .env.example .env
cp docker-compose.override.yml.example docker-compose.override.yml

Create a file named librechat.yaml in the LibreChat directory with this configuration:

version: 1.2.1
endpoints:
  custom:
    - name: "Ollama"
      apiKey: "ollama"
      baseURL: "http://host.docker.internal:11434/v1/"
      models:
        default: ["qwen3:8b"]
        fetch: true
      titleConvo: true
      titleModel: "current_model"

Start LibreChat using Docker Compose:

docker compose up -d

Open http://localhost:3080, create your local account, and select Ollama from the model endpoint picker.

Option C: Hermes Agent

Hermes Agent is a command-line agent tool. Install it using the script for your system:

Mac

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.zshrc

Windows (PowerShell)

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Restart PowerShell after installation.

Linux

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.bashrc

Agents require an expanded context window to hold multi-step tool calls. Create a file named Modelfile with:

FROM gemma4:31b
PARAMETER num_ctx 64000

Build the customized model and run the setup wizard:

ollama create gemma4-64k -f Modelfile
hermes setup

Choose Custom Endpoint, set Base URL to http://localhost:11434/v1, leave API key blank, and set model to gemma4-64k. Launch Hermes anytime by typing hermes in your terminal.

Frequently asked questions

Why is Docker required for Open WebUI and LibreChat?

Docker packages the entire web server, database, and front-end interface into a self-contained container. It ensures the software runs reliably across Mac, Windows, and Linux without requiring manual dependency installs.

Does Open WebUI store my chats or files on the internet?

No. When running Open WebUI locally, your chat history, accounts, and uploaded documents stay on your machine inside a local Docker volume. No telemetry or conversation data is sent out.

Can I access Open WebUI from my phone or laptop on home Wi-Fi?

Yes. Instead of browsing to localhost:3000, navigate to your host computer's local network IP address (e.g. http://192.168.1.50:3000) from any phone or tablet connected to your home Wi-Fi.

What can I use if I do not want to install Docker?

If you want to skip Docker entirely, download LM Studio or AnythingLLM. Both are standalone desktop apps with simple installers that connect directly to your local models.
