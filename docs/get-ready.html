Get ready

Two steps before you install anything: copy your projects out of your paid service, and find out what your computer can run.

1Save your current setup

Copy your project instructions and files out by hand before you change anything. The parts that make a project behave the way it does are its instructions and its files, and no AI service exports a whole project as one package you can import somewhere else.

  1. Make a folder called ai-migration, with one subfolder for each project you want to keep.
  2. Open each project and copy its custom instructions into a text file named instructions.md in that project's subfolder.
  3. Download each file attached to the project into a files subfolder, keeping the original names.
  4. Copy anything you want to keep from the service's saved memory or personalization settings into memory.md.
  5. As a backup, request the full account export. In Claude it is under Settings, then Privacy, then Export data. In ChatGPT it is under Settings, then Data controls, then Export data. For Gemini, use Google Takeout. The download link is emailed to you and expires, so save the file right away.

You can skip old chats. Most of them are not worth moving, and the instructions and files are what recreate the project.

Check: every project subfolder has an instructions.md and a files folder with every document you want the new setup to know about.

2Check your computer

Find out how much memory your computer has, because it decides which models you can run. The model has to fit in memory alongside everything else you have open.

Mac

Open the Apple menu and choose About This Mac. Note the chip (M1 to M4 or newer, or Intel) and the memory. On Apple Silicon the graphics share that same memory, so the memory number is the one that matters. Ollama's docs ask for macOS 14 Sonoma or newer. Intel Macs work but run models on the processor only, which is much slower.

Windows

Open Settings, then System, then About, and note the installed RAM. Then open Task Manager, choose Performance, and click GPU to see your graphics card and its dedicated memory. A recent NVIDIA card with 8 GB or more of its own memory makes local models much faster. Without one, models still run on the processor, just slower.

Linux

Run free -h to see your memory. If you have an NVIDIA card, nvidia-smi shows its model and memory. As on Windows, the card's own memory decides how big a model runs fast.

Free up disk space too. Keep at least 20 GB free for the apps and your first model, and plan for several more gigabytes for each extra model.

Check: you know your memory (RAM, and graphics memory on a PC) and you have 20 GB or more free.
