Get ready

Two steps before you install anything: copy your projects out of your paid service, and find out what your computer can run.

On this page

  2. Step 2: Check your computer

1Save your current setup

Copy your project instructions and files out by hand before you change anything. The parts that make a project behave the way it does are its custom instructions and its reference files. No AI service exports a whole project as one universal file you can import somewhere else.

  1. Make a folder on your computer called ai-migration, with one subfolder for each project you want to keep.
  2. Open each project in Claude, ChatGPT or your service, and copy its custom instructions into a text file named instructions.md inside that project's folder.
  3. Download each file attached to the project into a files subfolder, keeping the original names.
  4. Copy anything you want to keep from the service's saved memory or personalization settings into a file named memory.md.
  5. As a safety backup, request the full account export from your service:
    • Claude: Settings → Privacy → Export data.
    • ChatGPT: Settings → Data controls → Export data.
    • Gemini: Go to Google Takeout and select Gemini Apps.
    The download link is emailed to you and expires after a short window, so save the ZIP file to your disk when it arrives.

What normal looks like: inside your ai-migration folder, you see cleanly named folders for each project. Inside each project folder sits an instructions.md text file and a files/ folder containing your PDFs, notes, or spreadsheets.

If this goes wrong

  • If an export link from Anthropic or OpenAI never arrives, check your spam folder. If attachments cannot be downloaded in bulk from a project screen, open the file preview and save them individually.
  • You can't re-download a file you uploaded to a project: find the original on your computer first. If it only exists inside the project, ask the chat to print the file's full text and paste that into a new document.
  • The export email takes a while: big histories can take hours to package. Carry on and download the file as soon as the email lands, because the link expires.

Check: every project subfolder has an instructions.md and a files folder with every document you want the new setup to know about.

2Check your computer

Find out how much memory your computer has, because memory decides which models you can run. The model has to fit into memory alongside your operating system and web browser.

Mac

Click the Apple menu in the top-left corner and choose About This Mac (or System Settings → General → About). Note two numbers:

  • Chip: Apple Silicon (M1, M2, M3, M4 or Pro/Max/Ultra) or Intel. Apple Silicon uses unified memory shared between CPU and graphics, making it ideal for local AI. Intel Macs run models on the CPU only, which is much slower.
  • Memory: 8 GB, 16 GB, 24 GB, 36 GB, 48 GB, 64 GB, or more.
  • Operating system: macOS 14 Sonoma or newer is recommended by Ollama's documentation.

Windows

Open Settings → System → About, and look at Installed RAM (e.g. 16.0 GB). Then check your graphics card:

  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Click the Performance tab on the left.
  3. Click GPU at the bottom of the list. Look at the card name (e.g. NVIDIA GeForce RTX 4070) and note the Dedicated GPU memory (e.g. 12.0 GB).

An NVIDIA graphics card with 8 GB or more of dedicated VRAM runs local models at high speeds. If your GPU shows Intel Iris or AMD integrated graphics sharing system memory, models will run on the main CPU and RAM, which is slower but fully functional.

Linux

Open a terminal window and run:

free -h

Look at the Mem: total column. If you have an NVIDIA card installed, run:

nvidia-smi

Look for the total VRAM listed under Memory-Usage (e.g. 12288MiB).

Not sure which models match your hardware? Use the hardware checker tool to get an instant recommendation for your specific RAM and GPU.

Free up disk space too. You need at least 20 GB of free drive space for Docker, Ollama, and your first model. Check this in Finder on Mac, File Explorer on Windows, or using df -h on Linux.

If this goes wrong

  • If your disk has less than 20 GB free, empty your Downloads and Trash or run your system's built-in storage clean-up tool before continuing. Trying to download a 5 GB model on a drive with 3 GB free will freeze the installation midway.
  • Task Manager on Windows only shows a small list of apps: click More details at the bottom, then open the Performance tab.

Check: you wrote down your total RAM (and dedicated GPU memory if on PC), and verified you have 20 GB or more of free disk space.

Frequently asked questions

Do I need to export all my old chat history?

No. Most chat logs are not worth migrating. What gives a project its specific behavior and answers are its instructions and attached reference files. Focus on saving those.

What if my computer has less than 16 GB of RAM?

An 8 GB machine can still run smaller models like qwen3:4b. They answer quickly for writing drafts and short summaries, though they are less capable at complex reasoning and deep knowledge extraction.

Will saving my projects change anything in my paid account?

No. Copying out text files and downloading attachments changes nothing in your existing accounts. Leave your subscription active until you finish testing in Step 9.

How much free hard drive space do I actually need?

Keep at least 20 GB free. Ollama and Docker take a few gigabytes, and each downloaded model takes between 3 GB and 20 GB of storage.
