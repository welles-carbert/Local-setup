# Local AI Home Setup

A static site (plain HTML, CSS and JS, no build step) with a step-by-step guide to moving an AI workspace from paid subscriptions to free local AI.

- Site files live in `docs/`.
- Preview locally: `cd docs && python3 -m http.server 8000`, then open http://localhost:8000.
- Deploy on GitHub Pages: Settings > Pages > Deploy from a branch > `main` / `docs`.
- Before launch, work through `NOTES-before-launch.md`.
