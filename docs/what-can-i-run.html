Frequently asked questions

What happens if I try to run an AI model that is too large for my memory?

Your computer will either fail to load the model with an out-of-memory error, or it will spill into hard drive swap space. Swapping makes text generation painfully slow, often delivering only one word every several seconds.

Does my computer processor (CPU) matter if I have enough RAM?

Yes, but memory capacity and memory bandwidth matter more. On Macs, Apple Silicon chips include high-speed unified memory. On Windows and Linux PCs without a dedicated graphics card, modern CPUs run small models decently, but generation is significantly slower than with an NVIDIA GPU.

Can I increase my graphics memory (VRAM) without buying a new PC?

On standard PCs, VRAM is soldered directly onto your graphics card and cannot be upgraded independently. To get more VRAM, you replace the graphics card. On Apple Silicon Macs, memory is shared, but it is fixed at purchase time and cannot be expanded later.
